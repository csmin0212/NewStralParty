## 2. 규칙

| 항목 | 내용 |
|---|---|
| 행동 덱 | 등장 때 1장 공개 · 라운드 끝 보스 차례에 사용 · 새 라운드에 다음 장 공개 · `cycle` 순서 / `shuffle` 무작위 |
| 저지 | `breakAt` · 공개 뒤 보스 차례까지 그만큼 피해 · 빨강 성유물 |
| 그로기 | 저지 · 코어 노출 · 미사일 장치 파괴 · 흡수 때 미니언 2마리 이상 쓰러짐 → 다음 보스 차례까지 방어 0, 받는 피해 +1 |
| 2페이즈 | 체력 `phase2.at` · 이름 · 능력치 · 덱 교체 · `enter` 효과 |
| 보스 차례 순서 | 행동 → 게이지 · 침식 · 리조트 · 난로 → 미니언 (자폭 · 호출 · 이동) → 폭탄 · 모자 → 저주 → 부위 순환 |
| 공격 범위 미리 보기 | 범위 공격 · 곧 터질 폭탄 · 자폭 직전 미니언 · 곧 터질 저주 (빈 모자 제외) |
| 보스 스킬 피해 | 방어력 무시 (OJ 전투 밖 피해) |

### 에너미 특성

| 특성 | 에너미 | 내용 |
|---|---|---|
| `roam` | 좀도둑 · 카이텐저 · 슬럼피아 병사 · 화신 | 보스 차례 뒤 1~N칸 · 아군 칸 = 공격력 피해 · 거점 · 워프 · 에너미 칸 불가 |
| `chase` | 화신 | 가장 가까운 아군 쪽 |
| `steal` | 좀도둑 | 코인 훔치고 계속 이동 · 처치 = 보상 + 훔친 코인 |
| `fuse` | 오토마타 병사 · 화신 | N번째 보스 차례에 자폭 · 주변 피해 |
| `calls` | 스케반 간부 | N차례마다 옆 칸에 졸개 |
| `link` | 페로로 미니언 · 묘귀의 조각 · 미사일 유도 장치 | 받은 피해 → 보스 (미니언 남은 체력까지) |
| `decoy` | 고즈 분신 | 보스와 같은 모습 · 맞으면 피해 없이 사라짐 |

### 보드 표식 (멈추면 발동)

| 표식 | 효과 |
|---|---|
| 폭탄 | 다음 보스 차례에 주변 1칸 3 피해 · 해체 코인 +2 |
| 성유물 (초록) | 보스가 받는 피해 +1 (최대 3) |
| 성유물 (빨강) | 공개된 보스 행동을 끊는다 |
| 모자 | 셋 중 하나 코인 6 · 빈 모자 2 피해 · 다음 보스 차례에 남은 빈 모자 폭발 |
| 파이프 오르간 | 성가 방향을 아군 쪽으로 |
| 난로 | 난로 +3 · 체력 +2 |

### 아군 약화

방어 하락 · 공격 하락 · 기절 (다음 차례 쉼) · 위압 (차례 시작마다 체력 -1, 회복으로 해제) · 저주 · 이동 감소
