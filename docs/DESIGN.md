# 게임 설계 — 협동 PVE (초안)

PvP 경쟁 대신 **협동 보스 레이드**로 간다. 친구들이 한 팀이 되어 보드를 돌며 에너미를 잡고, 유물로 캐릭터를 강화해서, 진행도가 다 차기 전에 보스를 쓰러뜨린다. 기본 틀은 아스트랄 파티를 참고한다.

- **✅ 확정**: 정한 것
- **💡 제안**: 일단 이렇게 해 보자는 안. 바꿔도 된다
- **❓ 결정 필요**: 정해야 만들 수 있는 것

### 용어

| 용어 | 뜻 |
|---|---|
| 에너미 | 일반 몬스터. 보드 위를 돌아다니는 적 유닛 |
| 보스 | 판마다 정해진 최종 보스. 잡으면 승리 |
| 라운드 | 모든 플레이어가 한 턴씩 하면 1라운드 |
| 진행도 | 보스 기믹이 따라가는 시계. 라운드마다 +1, **플레이어 KO마다 +1** |
| 기믹 | 보스마다 진행도에 맞춰 일어나는 이벤트 (소환, 강화 등) |
| 유물 | 캐릭터를 강화하는 패시브 효과. 골라서 모은다 |
| 인카운터 | 이동 중에 에너미·보스와 만나는 것 |

---

## 1. 한 판의 흐름

```
[시작]  자리마다 자기 거점에서 시작 (보드 네 모서리)
   │
[라운드 반복]
   │   각자 턴: 주사위 → 이동 (도중에 인카운터) → 도착 칸 효과
   │   라운드 끝: 에너미·보스 페이즈 → 진행도 +1 → 기믹 발동
   │
[결과]  보스 처치 → 모두 승리 🎉
        진행도가 한계에 닿을 때까지 못 잡음 → 모두 패배
```

---

## 2. 진행도와 보스 기믹 — ✅

게임 길이는 **보스마다 다르다.** 보스마다 진행도에 따른 기믹 시간표가 있다.

```
예시 보스의 시간표
  진행도 1   에너미 4마리 소환
  진행도 3   보스 등장
  진행도 6   에너미 3마리 소환, 모든 에너미 공·방 +1
  진행도 9   에너미 3마리 소환, 모든 에너미 공·방 +1
  ...
  진행도 15~16 쯤까지 처치 목표 (밸런스 검토 때 정함)
```

- 진행도는 **라운드마다 +1**, **플레이어가 KO 될 때마다 +1** 오른다. KO가 많을수록 보스가 빨리 강해진다.
- ⚠️ **라운드 쿨타임 스킬은 진짜 라운드 기준이다.** KO로 진행도가 오를 때는 쿨타임이 줄지 않는다.
  - 그래서 엔진에 **라운드**와 **진행도**를 따로 센다.
- 시간표는 코드가 아니라 **데이터**로 만든다. 보스를 추가할 때 시간표만 쓰면 되게 한다.
- ✅ KO로 진행도가 올라서 기믹 시점에 닿으면 기믹은 **바로** 발동한다 (내 턴 도중이라도).
- ✅ 진행도가 보스의 패배 진행도에 닿으면 **패배**. 보스를 처치하면 **승리**.
- 💡 "모든 에너미 공·방 +1"은 지금 있는 에너미와 **이후 소환되는 에너미** 모두에 적용, 보스는 제외.
- 💡 소환은 균열(소환 칸)부터 채우고, 다 차면 본부 · 보스 칸 · 워프를 뺀 빈 칸에 나온다.
- ❓ 패배 진행도 (보스마다 다름. 밸런스 때)

> **구현됨.** 보스 데이터는 [src/data/bosses.ts](../src/data/bosses.ts) 한 파일. 지금은 위 예시를 그대로 쓴 **임시 보스**(HP 인원당 6, ATK 3, DEF 1, 반격형, 패배 진행도 16)이고, 진짜 보스가 정해지면 이 파일만 바꾸면 된다.
> 보스는 아직 보스 칸에 서 있기만 한다 (이동 · 라운드 끝 행동은 에너미 이동 때).

## 3. 인카운터 — ✅ 구현됨

> 지금 구현: 에너미 3종(경비 로봇·정찰 드론·불량배), 공격/놓아주기, 반격 때 방어/회피 직접 선택, 에너미 HP 유지, 전투 화면 연출.
> 에너미는 보스 시간표의 소환 기믹으로만 나온다.

이동하다 에너미·보스가 있는 칸을 **지나가거나 도착하면** 인카운터가 일어난다.

```
에너미가 있는 칸에 들어감
   │
   ├─ [놓아주기] → 아무 일 없이 남은 칸만큼 계속 이동
   │
   └─ [공격] → 내가 공격 (에너미가 방어/회피 판정)
         │
         ├─ 에너미가 살아 있고 [반격형]이면 → 에너미가 1회 반격
         │   [비반격형]이면 → 반격 없음
         │
         └─ 남은 칸만큼 계속 이동  (KO 당하면 이동 끝)
```

- 공격·방어·회피 계산 (EVA 능력치는 없앴다)
  - 공격값 = `d6 + ATK`
  - 방어: 피해 = `max(1, 공격값 - (d6 + DEF))`
  - 회피: **주사위 눈끼리** 비교한다. 내 `d6 > 상대 공격 주사위 눈`이거나 **내 눈이 6**이면 피해 0 (6은 6도 피한다, 원작), 아니면 공격값 그대로 받음
    - 예: 상대가 3을 굴리면 4 · 5 · 6이 나와야 피한다. 공격력은 피해량에만 들어간다.
    - 스킬로 회피 주사위를 여러 개 굴리면 가장 높은 눈을 쓴다.
- 한 번 이동하는 동안 인카운터가 여러 번 일어날 수 있다.
- 에너미의 공격을 아예 피하는 건 **특정 유물의 효과**로 가능하게 한다.
- 💡 **에너미 HP는 유지된다.** 내가 깎아 둔 에너미를 친구가 마무리할 수 있다.
- 💡 반격이 오면 플레이어가 **방어/회피를 직접 고르고 주사위를 직접 굴린다.**
- ✅ 굴리는 순서는 원작처럼 **공격하는 쪽이 먼저**. 반격은 에너미가 먼저 공격 주사위를 굴려 값을 보여 주고, 플레이어는 그걸 보고 카드와 방어/회피를 고른다.
- ✅ 카드를 내기 전에 **예상 범위**를 보여 준다: 내 공격 · 방어 범위, 적 방어 범위 또는 이미 굴린 적 공격, 예상 피해 · 명중률 · 회피 확률. 카드에 마우스를 올리면 그 카드를 낸 경우로 바뀐다.
- 💡 에너미가 방어를 쓸지 회피를 쓸지는 에너미마다 정해 둔다.

### 에너미 종류 (예시)

| 에너미 | 반격 | 방어 방식 | 특징 |
|---|---|---|---|
| 경비 로봇 | ❌ | 방어 | 약함. 초반 코인벌이 |
| 불량배 | ⭕ | 방어 | 평범 |
| 정찰 드론 | ❌ | 회피 | 공격력과 상관없이 주사위 눈 대결로 피한다 |
| 대형 경비 기계 (예정) | ⭕ | 방어 | 단단하고 보상이 큼 |

## 4. 에너미 · 보스 이동 — ✅

에너미와 보스도 **플레이어처럼 주사위를 굴려서 움직인다.**

- 💡 라운드 끝 에너미·보스 페이즈에 하나씩 차례로 굴려서 움직인다.
- ✅ 에너미가 움직이다 **플레이어가 있는 칸을 지나가면 공격한다.**
  - 💡 공격받는 플레이어가 방어/회피를 고른다. 자기 턴이 아닐 때도 고르게 되므로, 온라인에서는 그 플레이어에게 선택 창이 뜬다.
- ❓ 에너미가 갈림길에서는 어느 쪽으로 가나? (💡 가까운 플레이어 쪽, 없으면 랜덤)
- ❓ 소환된 에너미는 어디에 나타나나? (💡 보드의 스폰 지점 중 랜덤)

### 에너미 기믹 — ✅

에너미마다 고유 기믹이 있다. 예를 들면 이런 것들이다.

- 움직이기 전에 **주변 플레이어를 공격**한다
- 지나간 칸에 **함정을 설치**한다
- ...

- 💡 기믹은 "언제(이동 전, 이동 후, 공격받았을 때 ...) + 무엇을(공격, 함정, 소환, 강화 ...)" 조합의 **데이터**로 만든다. 에너미를 추가할 때 코드를 새로 짜지 않고 조합만 고르면 되게 한다.
- 보스 기믹(진행도 시간표)과 에너미 기믹(행동 패턴)은 따로 둔다.

## 5. 성장 — 코인 · 유물 · 상점

### 코인 — ✅

- **각자** 가진다.
- 에너미 처치, 코인 칸 등에서 얻는다.
- 상점에서 아이템·유물을 사는 데 쓴다.
- 상점에 들르면 **다른 플레이어에게 5코인 송금**할 수 있다. 아스트랄 파티 방식에서 다듬어도 된다.

### 유물 — ✅ (아스트랄 파티 참고)

유물을 골라 모아서 캐릭터를 강화한다. 얻는 방법은 세 가지다.

| 얻는 방법 | 방식 |
|---|---|
| 레벨업 | 레벨업할 때마다 후보 중 하나를 고른다 |
| 임무 달성 | 임무를 달성하면 유물을 받는다 |
| 유물 상점 | 상점에 들러 코인을 내고 산다 |

- 💡 고를 때는 후보 3개 중 1개를 고른다.
- 유물 예시: ATK +1, 반격 무시, 놓아주기 대신 몰래 지나가기, 코인 획득 +1, 회복량 증가 ...

### 상점

- 아이템 구매, 유물 구매, 코인 송금을 한다.
- ✅ 카드는 개인 덱으로 쓴다 (11번). 상점에서 산 카드는 쓰면 사라진다.
- ❓ 아이템 상점과 유물 상점은 **같은 칸**인가 **다른 칸**인가?

### 레벨 · 임무

- ✅ 레벨업: **자기 거점에서 코인을 내고** 한다. 게임을 시작한 칸이 그 플레이어의 거점 (지나가거나 멈추면).
- ✅ 레벨은 **성(★)** 으로 센다. 0성에서 시작해 3성까지 (레벨업 3번).
- ✅ 레벨업 비용 15 → 20 → 25코인 (임시, 밸런스 때 다시)
- ✅ 레벨업 능력치는 **캐릭터마다 다르다** → 10번 캐릭터 항목. 최대 HP가 오르면 지금 HP도 같이 오른다.
- ❓ 임무는 어떤 것들인가? (💡 예: 에너미 3마리 처치, 코인 30개 모으기, 회피 성공 2번. 각자 받는 임무 vs 팀 임무)

---

## 6. KO — ✅ 구현됨

- HP 0이 되면 KO. 그 자리에 눕는다.
- **다음 라운드는 쉬고**, 그다음 라운드 자기 차례에 부활한다.
- 패널티: **진행도 +1**. 코인은 잃지 않는다.
- ✅ 부활: **쓰러진 자리**에서 **HP 가득**.

---

## 7. 전투 연출 (UI)

인카운터가 일어나면 보드 위에 **전투 화면**이 뜬다.

```
┌──────────────────────────────────────┐
│   [내 캐릭터]        VS     [에너미]   │
│    HP ■■■■□                  HP ■■□   │
│                                      │
│        [ ⚔ 공격 ]   [ 놓아주기 ]        │
└──────────────────────────────────────┘
```

- 공격할 때, 맞을 때, 방어할 때, 회피할 때 캐릭터 이미지가 바뀐다.
- 그래서 캐릭터·에너미·보스마다 **전투용 포즈 이미지**가 필요하다. 캐릭터 작업 때 규격서에 추가한다.
  - 기본(대기), 공격, 피격, 방어, 회피
- 주사위는 직접 눌러서 굴린다 (공격 주사위, 방어/회피 주사위).

## 8. 지금 엔진에서 바뀌는 것

| 지금 (1단계) | 바뀜 |
|---|---|
| 몬스터 = 칸 효과 | 에너미 = 보드 위 유닛 (위치, HP, 반격형 여부), 주사위로 이동 |
| 칸에 도착해야 효과 | 지나가기만 해도 인카운터 → 공격/놓아주기 → 이어서 이동 |
| 몬스터 전투 자동 | 공격 주사위, 방어/회피 선택을 플레이어가 직접 |
| 레벨 3 = 승리 | 보스 처치 = 승리, 진행도 한계 = 패배 |
| 라운드만 셈 | 라운드 + 진행도 따로 셈, 보스 기믹 시간표 |
| KO → 코인 절반, 본부 | KO → 1라운드 쉬고 부활, 진행도 +1 |
| 카드 | 아이템 + 유물 + 상점 + 임무 |
| 공용 본부 1개 | 플레이어마다 자기 본부 (레벨업 · 부활) |
| 몬스터는 가만히 있음 | 에너미마다 기믹 (이동 전 공격, 함정 설치 ...) |

## 9. 결정할 것 정리

**정해서 구현까지 한 것:** 반격 때 방어/회피 직접 선택, KO로 넘긴 기믹은 바로 발동, 부활은 쓰러진 자리 HP 가득

**첫 진짜 보스 만들 때 필요**

1. 보스 이름 · 스탯 · 시간표 · 패배 진행도 (지금은 임시 보스)

**에너미 이동 구현 전에 필요**

2. 에너미 갈림길 규칙
3. 첫 에너미들의 기믹 몇 가지
4. 보스도 움직이나, 라운드 끝에 따로 행동하나

**성장 구현 전에 필요**

5. ~~캐릭터별 레벨업 능력치~~ → 캐릭터마다 정함 (10번)
6. 임무 종류, 개인 임무 vs 팀 임무
7. 아이템 상점과 유물 상점이 같은 칸인가

**밸런스 때**

8. 레벨업 비용, 에너미 · 보스 수치

## 10. 캐릭터 — ✅ (하나씩 추가 중)

- 캐릭터마다: 기본 HP · ATK · DEF, **시작 코인**, 1 · 2 · 3성 능력치 상승 (HP · ATK · DEF · 이동거리), 액티브 스킬 1개, 패시브 1개, 잠재 능력 1개.
- 데이터는 `src/data/characters.ts`, 효과는 `src/engine/skills.ts`, 그림은 `public/assets/characters/<id>/`.
- **액티브 스킬**: 자기 차례에 주사위 굴리기 전 [스킬] 버튼으로 쓴다. 한 턴에 한 번. 재사용 대기시간은 **라운드** 단위 (KO로 넘어간 진행도로는 줄지 않는다).
- **잠재 능력**: 지금은 시작 화면에서 플레이어마다 켜고 끈다 (나중에 해금 조건이 생기면 바꾼다).
