# 에셋 규격서

NewParty에 들어갈 그림 에셋 목록과 규격. 이 문서를 보면서 뽑아 오면 된다.

- 규격은 **최소 크기** 기준이다. 더 크게 뽑아도 되고, 최종 크기·포맷 변환은 넣을 때 처리한다.
- 정확히 맞추기 어려우면 비슷하게만 맞춰도 된다. 크기 조정, 배경 제거, 여백 정리는 넣을 때 할 수 있다.
- **제일 중요한 건 스타일 통일**이다. 아래 [스타일 가이드](#1-스타일-가이드)부터 정하고 시작하자.

---

## 0. 전달 방법

1. 뽑은 원본은 프로젝트의 **`assets-raw/`** 폴더에 넣는다. 파일 이름은 대충이어도 된다.
   - 이 폴더는 git에 올라가지 않는다 (원본은 용량이 크므로).
2. 어떤 파일이 무엇인지 알려 주면 정리해서 `public/assets/`에 아래 이름으로 넣는다.
   배경 제거, 크기 조정, WebP 변환도 이때 한다.
3. 화면에 올려 보고 같이 확인한다.

---

## 1. 스타일 가이드

> 정해지면 여기에 적어 두고, 모든 에셋을 이 기준으로 뽑는다.

| 항목 | 정한 값 |
|---|---|
| 전체 분위기 | _(예: 밝은 애니메이션 풍 / 판타지 / 우주 / 파스텔)_ |
| 그림체 | _(예: 셀 셰이딩 2D, 굵은 외곽선)_ |
| 색감 | _(예: 채도 높은 원색 / 부드러운 파스텔)_ |
| 조명 방향 | _(예: 왼쪽 위에서)_ |
| 공통 프롬프트 | _(모든 프롬프트 앞에 붙일 스타일 문구)_ |

### 통일 규칙

- **같은 스타일 문구를 모든 프롬프트 앞에 붙인다.** 가능하면 같은 모델과 같은 스타일 설정을 쓴다.
- **그림 안에 글자를 넣지 않는다.** 이름, 숫자, 효과 설명은 전부 화면에서 따로 그린다. AI가 그린 글자는 깨지기 쉽고, 나중에 고칠 수도 없다.
- **조명 방향과 시점을 통일한다.** 그림자가 드는 방향이 서로 다르면 판이 어색해 보인다.
- 대상을 **가운데에** 두고, 가장자리에 **여백을 10% 정도** 남긴다. 잘린 그림은 쓸 수 없다.

### 배경

- 투명 배경 표시가 있는 것은 **투명 PNG**로 받는 게 가장 좋다.
- 투명이 안 되면 **단색 배경**으로 뽑는다. 대상에 없는 색이 좋다 (예: 초록 캐릭터면 마젠타 배경). 그림자나 바닥은 그리지 않는다.

## 2. 우선순위

한 번에 다 뽑지 말고, **1차분**으로 분위기를 먼저 맞춘 다음 나머지를 뽑자.

| 차수 | 무엇을 | 왜 |
|---|---|---|
| **1차** | 캐릭터 1명(말 + 얼굴), 칸 3종(본부·코인+·몬스터), 배경 1장 | 판 위에 올려 보고 스타일 확정 |
| 2차 | 나머지 칸, 나머지 캐릭터 3명(4인 플레이 분) | 1단계 핫시트 화면을 실제 그림으로 교체 |
| 3차 | 캐릭터 전신 일러스트, 몬스터, 카드, UI 아이콘, 로고 | 시작·선택·승리 화면, 전투 연출 |
| 이후 | 캐릭터 추가(총 6~8명), 표정 변화, 보스 | 4단계 콘텐츠 |

---

## 3. 캐릭터

플레이어가 고르는 캐릭터. 처음엔 **4명**(4인 플레이), 나중에 6~8명까지 늘린다.
한 캐릭터당 아래 3장이 필요하다. **같은 캐릭터로 보여야** 하니, 의상·머리색·소품을 프롬프트에 똑같이 적는다.

| 파일 | 용도 | 크기 | 포맷 | 메모 |
|---|---|---|---|---|
| `characters/<id>/token.png` | 판 위의 말 | 512×512 | 투명 PNG | SD(치비) 비율, 전신, 정면 또는 살짝 위에서. **모든 캐릭터 같은 각도·같은 크기 비율** |
| `characters/<id>/portrait.png` | 패널 · 턴 표시 얼굴 | 512×512 | 투명 PNG | 어깨 위 상반신, 정면, 얼굴이 가운데 |
| `characters/<id>/full.png` | 캐릭터 선택 · 승리 화면 | 1024×1536 (세로 2:3) | 투명 PNG | 전신 일러스트, 포즈 자유 |

- `<id>`는 영문 소문자 이름 (예: `luna`, `kai`).
- 캐릭터마다 **대표 색**을 하나 정해 주면, 그 색을 화면의 플레이어 색으로 쓴다.
- 말(token)은 판 위에서 50~70px 정도로 작게 보인다. **실루엣이 단순하고 색이 또렷해야** 작게 봐도 누군지 알 수 있다.

### 나중에 (선택)

| 파일 | 용도 |
|---|---|
| `characters/<id>/portrait-happy.png` | 레벨업 · 승리 |
| `characters/<id>/portrait-hurt.png` | 피해 · KO |

## 4. 보드

### 칸 (8종)

| 파일 | 칸 | 분위기 예시 |
|---|---|---|
| `tiles/base.png` | 본부 | 성, 깃발, 캠프. **다른 칸보다 눈에 띄게** |
| `tiles/coin-plus.png` | 코인+ | 금화 더미, 보물 |
| `tiles/coin-minus.png` | 코인- | 깨진 항아리, 구멍 난 주머니 |
| `tiles/card.png` | 카드 | 카드 더미, 마법진 |
| `tiles/monster.png` | 몬스터 | 동굴 입구, 위험 표시 |
| `tiles/heal.png` | 회복 | 샘물, 약초 |
| `tiles/warp.png` | 워프 | 포털, 소용돌이 |
| `tiles/empty.png` | 빈 칸 | 평범한 발판 |

- 크기 **512×512**, **투명 PNG**.
- **모양과 시점을 전부 통일한다.** 추천: 둥근 발판(원형 또는 둥근 사각형)을 **약 30° 위에서 내려다본** 모습. 마리오 파티 같은 느낌.
- 발판 **테두리와 바닥 두께는 모든 칸이 같게**, 윗면 그림과 색만 다르게 하면 통일감이 좋다.
- 판 위에서는 70~90px 정도로 작게 보인다. 칸 종류를 **색만 보고도 구분할 수 있게** 칸마다 대표 색을 다르게 한다.

### 배경

| 파일 | 용도 | 크기 | 포맷 |
|---|---|---|---|
| `board/background.jpg` | 보드 뒤 배경 | 2560×1440 (16:9) | JPG/PNG (투명 필요 없음) |

- 보드 판(가로로 긴 직사각형, 약 16:10)이 **가운데에 올라간다.** 가운데는 칸이 잘 보이도록 **단순하고 어둡거나 흐리게**, 볼거리는 가장자리에 둔다.
- 칸보다 **채도와 대비가 낮아야** 칸이 묻히지 않는다.
- 나중에 보드 맵을 여러 개 만들면 맵마다 배경 1장씩 필요하다.

### 길 (선택)

칸 사이를 잇는 길은 지금은 코드로 그린다. 길을 그림으로 원하면 아래처럼 뽑는다.

| 파일 | 용도 | 크기 |
|---|---|---|
| `board/path.png` | 칸 사이를 잇는 길 조각 (가로로 이어 붙일 수 있게) | 256×64, 투명 PNG |

## 5. 몬스터

| 파일 | 용도 | 크기 | 포맷 |
|---|---|---|---|
| `monsters/slime.png` | 몬스터 칸 전투 연출 (지금 규칙의 '슬라임') | 512×512 | 투명 PNG |
| `monsters/<id>.png` | 이후 추가 몬스터 | 512×512 | 투명 PNG |
| `monsters/boss.png` | 보스 (코인 1등 추적) | 1024×1024 | 투명 PNG |

- 캐릭터와 **같은 그림체**로, 무섭기보다 귀여운 쪽이 파티 게임에 어울린다.

## 6. 카드

| 파일 | 카드 | 효과 |
|---|---|---|
| `cards/dash.png` | 질주 | 이번 이동 +2칸 |
| `cards/double-dice.png` | 더블 주사위 | 주사위 2개 |
| `cards/bandage.png` | 붕대 | HP +4 |

- 크기 **512×720** (세로 5:7), PNG.
- **카드 안쪽 그림만** 뽑는다. 카드 테두리, 이름, 효과 글씨는 화면에서 그린다.
- 카드가 늘어나도 같은 구도·같은 톤을 유지한다.

## 7. UI 아이콘 · 로고

| 파일 | 용도 | 크기 |
|---|---|---|
| `ui/coin.png` | 코인 | 256×256 |
| `ui/heart.png` | HP | 256×256 |
| `ui/star.png` | 레벨 | 256×256 |
| `ui/card-back.png` | 카드 뒷면 | 512×720 |
| `ui/logo.png` | 시작 화면 로고 | 가로형, 1600×600 정도 |

- 전부 **투명 PNG**.
- 아이콘은 20~32px로 작게 쓰인다. **디테일보다 또렷한 모양**이 중요하다.
- 로고는 글자가 들어가는 유일한 에셋이다. AI 글자가 깨지면 그림 부분만 뽑아 오면 된다. 글자는 폰트로 얹을 수 있다.
- 주사위는 코드(3D CSS)로 만들 예정이라 그림이 필요 없다. 원하는 디자인이 있으면 참고 이미지만 줘도 된다.
