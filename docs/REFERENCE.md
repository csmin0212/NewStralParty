# 원작 화면 레퍼런스 (아스트랄 파티)

화면을 만들 때 **원작 화면 구성 · 움직임을 최대한 그대로** 따른다. 색과 그림은 우리 것(블루 아카이브 풍 학원 도시)으로 바꾼다.
원작 파일을 뜯지 않는다. 스크린샷 · 영상만 보고 따라 만든다.

출처: [Steam 상점 페이지 스크린샷 7장](https://store.steampowered.com/app/2622000/) + 사용자가 준 인게임 · 로비 · 캐릭터 화면 캡처.

---

## 0. 원작 화면 공통 문법

| 요소 | 원작 | 우리 쪽 |
|---|---|---|
| 핵심 선택 버튼 | **큰 원형 버튼** (Let Go / ATTACK, Odd / Even, Exit / GO, Move). 굵은 이탤릭 흰 글자, 진한 테두리 | 이동 버튼만 원형. 나머지는 사각 버튼 → **전부 원형으로** |
| 패널 | **어두운 패널 + 위에 두툼한 색 탭** (분홍 "Shop" 탭) | 흰 반투명 카드 → 학원 도시 색(남색 패널 + 하늘색 탭)으로 같은 구조 |
| 강조 버튼 색 | 라임 초록 · 핫핑크 · 파랑 | 하늘색 하나 → **확인 = 하늘/라임, 취소 = 핑크** 처럼 역할별로 |
| 캐릭터 · 몬스터 | **흰 테두리 스티커** 같은 SD | 동그란 아바타 · 배지 → 그림 받으면 스티커 테두리(drop-shadow 4겹) |
| 글자 | 만화풍 굵은 글자, 외곽선, 흩뿌린 "FIGHT! DUEL!" | 연출에만 일부 |
| 레터박스 | 전투 · 이벤트 때 위아래 검은 띠 | 없음 |

## 1. 인게임 HUD — ✅ 대부분 따라감

사용자 캡처 (1, 11번째 이미지) 기준.

- 왼쪽 위: `☰` · `01 라운드` · `…` · `승리 조건 ?` → ✅ (맵 이름 자리에 원작은 "승리 조건/맵 설명" 버튼)
- 위 가운데: 임무 · 라운드 트랙 → ✅ 진행도 트랙
- 왼쪽: **1st/2nd 순위 + SD 얼굴 + 큰 HP(9/9) + 코인 + 별 3개** → ✅ (순위 · SD 얼굴은 캐릭터 그림 필요)
- 왼쪽 아래: **현재 캐릭터 큰 일러스트** + ATK · DEF 아이콘 → ✅ 자리만 (일러스트 필요)
- 아래 가운데: **손패가 부채꼴로 겹쳐 화면 아래로 반쯤 잘려** 있음 → ⚠ 지금은 나란히 세움. **부채꼴 · 반쯤 잘림으로 바꿀 것**
- 오른쪽 아래: `스킬` 버튼 + `카드 0/1` + **큰 원형 "이동 GO GO GO"** → ✅ (스킬 버튼은 스킬 시스템 때)
- 오른쪽 세로: 이모지 · 채팅 · 검색 · 위치 아이콘 버튼 → 온라인 때
- 맵 위 에너미: **이름 + 레벨 라벨**(젤리 전사 1) **+ HP 숫자**(14/21)가 머리 위에 → ⚠ 지금은 배지만. **이름 · HP 라벨 추가**
- 현재 차례 말: 발밑에 빨간 링 → ✅ 노란 링

## 7. 로비 · 캐릭터 — 아직 없음

사용자 캡처 기준.

- 로비: 화면 가득 **키 일러스트**, 오른쪽에 **캐릭터 / 상점 / 뽑기 / 이벤트 카드 메뉴**(캐릭터 얼굴이 크게 들어간 기울어진 카드), 오른쪽 아래 큰 **게임 시작**, 아래 바에 프로필 · 재화 · 아이콘 메뉴
- 캐릭터 목록: 왼쪽 큰 전신 일러스트 + 이름 띠 + 인연 하트, 오른쪽 **세로 카드 그리드** (얼굴 카드 + 이름 띠), 정렬 · 상세 정보 버튼
- 캐릭터 상세: 같은 왼쪽 일러스트 + 오른쪽 **탭(프로필 · 계약 · 스킨 · 이모티콘)**, 안에 다시 **스킬 · 레벨업 · 잠재 능력 · 프로필** 버튼
  - 스킬: ATK · DEF · HP 아이콘 수치, 액티브(쿨타임 시계) · 패시브 설명 띠
  - 레벨업: 레벨 1~6마다 "N성 도달 시 …" 목록
