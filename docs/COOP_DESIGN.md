## 1. 판

| 항목 | 원작 | 우리 |
|---|---|---|
| 인원 | 2~4 (빈자리 CPU) | 같음 |
| 캐릭터 중복 | 캐릭터당 1명 | 같음 |
| 시작 HP | 캐릭터 최대 HP | 같음 |
| 시작 코인 | 미확인 | 5 `임시` |
| 시작 손패 | 6장 (보통 · 어려움) | 6장 |
| 손패 한도 | 8장 (2026 기준, 예전 7) · 차례 끝에 넘친 만큼 버림 | 8장 |
| 차례마다 코인 | 없음 | 없음 |
| 라운드 | 플레이어 전원 → 몬스터 · 보스 (맵별 순서) | 같음 |
| 진행도 | 라운드마다 +1 · KO마다 +1 · 과제로 −1 | 같음 |
| 패배 | 진행도가 맵 한계에 닿으면 (17~20) | 보스별 `defeatAt` |
| 승리 | 메인 보스 처치 | 같음 |

## 2. 차례

| 순서 | 내용 |
|---|---|
| 0 | 차례 시작: 힐 스택 회복 · 칩 · 상태 발동 |
| 1 | 행동: 효과 카드 (1장, 칩 · 스킬로 +, 최대 9) · 액티브 스킬 · 순서 자유 |
| 2 | 이동 주사위 1~10 + 이동력 (합 0이면 제자리 · 한 번 이동 최대 10) |
| 3 | 갈림길에서 길 고르기 |
| 4 | 지나가는 칸: 상점 · 칩 상점 사용 · 내 거점 · 확인 지점에서 멈추기 선택 |
| 5 | 지나가는 몬스터: 싸우기 / 보내기 (한 이동에 여러 번) |
| 6 | 멈춘 칸: 전투 → 떨어진 코인 → 함정 · 설치물 → 칸 효과 |
| 7 | 차례 끝: 손패 한도 · 힐 스택 절반 (올림) · 표식 −1 |
| 라운드 끝 | 몬스터 · 보스 행동 → 진행도 +1 → 진행도 이벤트 |

## 3. 칸

| 칸 | 원작 | 효과 | 발동 |
|---|---|---|---|
| `base` 거점 | 起始点 | 체력 +2 · 코인이 되면 1성 오름 · 내 거점은 지나가며 멈추기 선택 | 멈춤 |
| `checkpoint` 확인 지점 | 保障点 | 거점과 같음 · 누구나 | 멈춤 |
| `shop` 상점 | 商店 | 카드 3장 (장당 3) · 정확히 멈추면 1장 공짜 · 송금 5 (방문마다 1번) | 지나감 · 멈춤 |
| `chipShop` 칩 상점 | 筹码商店 | 유물 3개 중 1개 · 10 + 5 × 산 수 | 지나감 |
| `monster` 몬스터 | 怪物 | 맵 몬스터 1마리 소환 → 바로 전투 | 멈춤 |
| `assault` 돌격문 | 怪物突击门 | 판 위 몬스터 하나 골라 그 칸으로 · 싸울지 선택 | 멈춤 |
| `heal` 회복 | 恢复 | 체력 +2 | 멈춤 |
| `card` 카드 | 卡牌奖励 | 카드 2장 | 멈춤 |
| `windfall` 횡재 | 天降横财 | 코인 2 · 3 · 4 · 5 · 10 중 하나 | 멈춤 |
| `calamity` 재앙 | 天降横祸 | 2 피해 | 멈춤 |
| `event` 이벤트 | 全员事件 | 전원 대상 무작위 이벤트 | 멈춤 |
| `haste` 질주 | 疾行 | 한 번 더 굴려 이동 | 멈춤 |
| `warp` 포털 | 传送门 | 다른 포털로 무작위 이동 | 멈춤 |

원작 맵 예 (星趴·梦想号, 13 × 11): 질주 4 · 카드 4 · 이벤트 8 · 재앙 6 · 몬스터 8 · 포털 4 · 회복 4 · 횡재 5 · 거점 4 · 상점 3 · 칩 상점 1 · 돌격문 4 · 확인 지점 1 = 56칸

- 맵 전용 칸 (유사 · 컨베이어 · 빙판 · 단서 · 시계탑 · 스포트라이트 · 사탕 자판기 · 반성실)은 위 구성 위에 얹는다 → [SYSTEMS.md 보스 맵](SYSTEMS.md#보스-맵)
- `coinPlus` · `coinMinus` · `spawn` · `empty`는 원작에 없다 → 횡재 · 재앙 · 몬스터로 바꾼다

## 4. 전투

| 항목 | 값 |
|---|---|
| 공격값 | 공격력 + 주사위 (1~6) + 공격 카드 보너스 |
| 방어값 | 방어력 + 주사위 (1~6) + 방어 카드 보너스 |
| 방어 | 피해 = max(1, 공격값 − 방어값) |
| 회피 | 내 주사위 > 상대 주사위 → 0 · 상대가 6이면 6 · 실패하면 공격값 전부 |
| 몬스터 | 회피하지 않는다 (예외: 金小鱼) · 카드를 쓰지 않는다 |
| 반격 | 몬스터마다 정해짐 · 내 공격 뒤 몬스터가 공격 |
| 전투 코스트 | 3 · 성마다 +1 · 최대 6 |
| 전력 공격 | 최종 공격값 × 1.5 (올림) · 겹치지 않음 |

| 회피 필요 | 상대 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 내 주사위 | 2+ | 3+ | 4+ | 5+ | 6 | 6 |

| 전투 카드 | 코스트 | 효과 |
|---|---|---|
| 공격 강화 (중) · 방어 강화 (중) | 1 | +1~3 |
| 공격 강화 (대) · 방어 강화 (대) | 2 | +1~6 |
| 공격 강화 (특대) · 방어 강화 (특대) | 3 | +1~10 |
| 그림자 습격 | 2 | 공격력 +3 · 반격 없음 |
| 명검 (名刀:嘎呜切) | 4 | 공격력 +1~20 |
| 축적 | 5 | 공격력 +5 · 전력 공격 1장 |
| 전력 공격 | 3 | 공격력 +6 · 최종 × 1.5 |

## 5. KO

| 항목 | 값 |
|---|---|
| 진행도 | +1 |
| 코인 | 잃지 않음 |
| 차례 | 이번 차례 · 다음 차례 쉼 |
| 부활 | 다음 차례에 체력 가득 |
| 쓰러진 동안 | 공격받지 않음 · 아군 효과도 받지 않음 |
