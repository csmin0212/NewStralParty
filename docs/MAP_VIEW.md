# 중앙 학원가 맵 표현

첨부한 아스트랄 파티 인게임 화면의 연결된 지형, 사선 카메라, 보행로 위 이벤트 칸 배치를 참고한 2.5D 맵입니다. 흰색·하늘색 학원 도시 디자인을 유지합니다.

- 외곽 보행로와 중앙 지름길을 하나의 도시 지면에 연결했습니다.
- 두 중정에 교사, 창, 나무, 벤치, 수반을 배치했습니다.
- 칸·말·에너미·경로 화살표에 동일한 사선 좌표 변환을 적용했습니다.
- 갈림길의 방향 설명도 화면 기준 대각선 방향으로 표시합니다.
- 화면이 좁아지면 맵을 축소하고 패널을 아래에 배치합니다.

이동 그래프와 전투 규칙은 기존 보드 데이터를 사용합니다. 지형은 src/ui/campusMap.ts, 게임 칸과 말은 src/ui/boardView.ts에서 그립니다. 현재는 고정 시점이며 자유 카메라와 학생 캐릭터 그림은 포함하지 않습니다.
