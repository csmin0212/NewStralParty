# 카드 밸런스 검토

카드 42장을 원작 카드([CARD_REFERENCE.md](CARD_REFERENCE.md))와 하나씩 맞춰 본 결과. 검토일 2026-10-24.

- ✅ 원작 그대로 (수치 · 효과 같음, 이름만 바꿈)
- ⚠ 원작에 있지만 바꿈
- ❌ 원작에 없음

비교 기준이 되는 우리 게임 수치: 일반 에너미 체력 2~5 (경비 로봇 3 · 정찰 드론 2 · 불량배 5), 보스 체력 6 × 인원 (4명이면 24) · 공격 3 · 반격함, 플레이어 체력 9 · 공격 1~2.

## 2. 밸런스 조정 — ✅ 적용함 (2026-10-24)

우리 에너미 체력이 2~5로 작아서, 원작 수치 그대로인 피해 카드가 상대적으로 세다.

| 카드 | 문제 | 적용 |
|---|---|---|
| 그림자 습격 | 보스 반격까지 막았다 | 반격 없음은 보스 제외 |
| 벽돌 | 5 피해 = 불량배 체력 전부, 3장까지 | 2장 제한 (피해 5는 원작 그대로) |
| 새총 | 원작 PvP 카드, 0포인트 · 조건 없음 | 1성 · 2포인트 |
| 명검 | 1성에서 +1~20 | 2성 |
| 전술적 후퇴 | 3코인 고정으로 보스 반격을 늘 피한다 | 코인 성 × 3 (최소 3) |
| 질주 | 원작에 없음, 3장까지 | 2장 제한 |
| 랜덤 포털 | 워프 칸이 1개라 늘 같은 칸 | 워프 칸 추가 (6번 → 14번) |
| 액셀 | 원작보다 약함 (높은 눈 1개) | 원작처럼 공격 주사위 2개 합 |
| 너도 나도 | 모나와 겹치면 카드가 계속 늘어난다 | 2포인트 |
| 총공격 · 긴급 호출 · 매그넘 · 불타는 의지 · 실드 카운터 | 원작 별 비용을 낮추거나 뺐다 | 그대로. 플레이해 보며 조정 |

## 3. 확인하지 못한 것

- AP 공격 · 방어 강화 (중 · 대), 그림자 습격, 전력 공격의 전투 코스트 (조사 자료에 없어 추정)
- AP 몬스터 · 보스의 실제 체력 (피해 카드가 원작에서 얼마나 센지 정확히 비교하려면 필요)
